# Motion Garden

[![Release](https://img.shields.io/github/v/release/kleenpulse/shadow-garden?label=release&color=8b5cf6)](https://github.com/kleenpulse/shadow-garden/releases) [![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Support: Buy me a coffee](https://img.shields.io/badge/support-buy%20me%20a%20coffee-FFDD00)](https://buymeacoffee.com/Vxrcel)

An animation-forward React component showcase — a dark, instrument-bench docs shell for browsing, tuning, and copying production-ready motion components. The demo copy still nods to _The Eminence in the Shadow_, where the original name came from.

Every component ships with a live preview, a Controls panel that tunes each prop in real time, the source on a Code tab, an install block, a Props API table, and a one-click **agent brief** — full source, dependency closure, props and integration rules in one paste for Claude Code, Cursor or any coding agent. All of it is generated from a single registry entry per component, so the docs never drift.

Live at **[motion-garden.netlify.app](https://motion-garden.netlify.app)**. Free and open source under MIT: every component's source, props and agent brief are open to everyone.

Agents can start at [`/llms.txt`](https://motion-garden.netlify.app/llms.txt): a registry-generated index of every component, its page and its prop count, following the [llms.txt](https://llmstxt.org) convention. It also lists the JSON endpoints under `/api/agent/` that search the catalog, describe a component and return its integration brief. Add `.md` to any component URL (for example [`/components/waves.md`](https://motion-garden.netlify.app/components/waves.md)) to get that brief as Markdown.

## Open agentic website

Motion Garden is also an [open agentic website](https://github.com/cognizant-ai-labs/agentic-web). Open **Ask the Garden** on any catalog page and a two-agent network, running in your browser on the AI provider and key you choose, finds components, tunes the live preview's controls for you and hands over the MIT source. Other agentic websites can call the same network at `https://motion-garden.netlify.app/agent/motion_garden` to search the catalog and fetch component code from their own chat.

The assistant sends your messages, and the page data it reads, to the AI provider you pick. It only changes the bench (control values and which component is open), all of which you can undo. Details, files and checks: [`public/agent/README.md`](public/agent/README.md).

## Getting started

Prerequisites: [Bun](https://bun.sh) 1.2+.

```bash
bun install
bun dev
```

Open [http://localhost:3000](http://localhost:3000).

To verify the site in Google Search Console, pick the "HTML tag" method and set `GOOGLE_SITE_VERIFICATION` to the tag's `content` value, then redeploy.

## Deploying

The site deploys to [Netlify](https://www.netlify.com), which runs Next.js through its OpenNext runtime (no adapter to install). Build settings live in [`netlify.toml`](netlify.toml).

```bash
netlify deploy --build --prod
```

Environment variables (all optional; without them the matching feature turns off quietly):

| Variable | What it enables |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Canonical URLs, sitemap and OG links. Set it to the deployed origin. |
| `DATABASE_URL` | View counts, favorite counts and the feedback form (Postgres). |
| `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | The live "people here now" presence count. |

Env values are read at build time, so change one and redeploy.

## Tech stack

- Next.js 16 (App Router, Cache Components / PPR on), React 19, TypeScript strict, Bun.
- Tailwind v4 (CSS-first, no config file — all tokens live in `app/globals.css`).
- nuqs, Shiki, Zustand, motion/react, gsap, ogl, cmdk, react-colorful, next-themes.
